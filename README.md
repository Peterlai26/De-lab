# สนามฝึก DE

เว็บเรียนและฝึก Differential Equations แบบเกม (บทเรียนสั้น 18 บท รวมลาปลาซ + เกมฝึก 6 แบบ) เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้อง build

## มีอะไรบ้าง
- บทเรียนสั้น 18 บท (บทนำ, สมการอันดับ 1, เชิงเส้นอันดับ n, การแปลงลาปลาซ)
- เกมฝึก 6 แบบ ทุกเกมมีโหมดง่าย/ยาก
  - นักสืบสมการ 44 ข้อ · จับผิดเฉลย 27 ข้อ · เรียงเฉลย 22 ข้อ · ย้อนรอยคำตอบ 28 ข้อ
  - แล็บปิดตาย 29 ห้อง (สุ่ม 5 ห้องกลาง + 1 ห้องสุดท้ายต่อรอบ) · สนามทิศทาง 8 สมการตัวอย่าง
- ทบทวนจุดที่พลาด: ข้อที่ตอบพลาดจะถูกเก็บไว้ให้ทำซ้ำ ตอบถูกตั้งแต่ครั้งแรกเมื่อไรก็ออกจากรายการ
- โหมดคู่ติว (เปิดในกล่อง "สำหรับพี่ติว" หน้าแรก): ตัวอักษรใหญ่ขึ้น ทุกโจทย์มีเฉลยกับคำถามชวนคิดไว้ถามน้องตอนฉายจอ

## แก้ไขและดูผล
เปิด `index.html` ในเบราว์เซอร์ได้เลย
